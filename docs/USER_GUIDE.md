# 使用说明 · ppt-generator

> 面向**使用者**。开发者请看 [`docs/DEVELOPMENT.md`](DEVELOPMENT.md)；agent 执行手册是 [`KNOWLEDGE.md`](../KNOWLEDGE.md)。

---

## 一、这是什么

一个跑在**你自己电脑上**的幻灯片生成器，两条独立的路：

| 路线 | 你给它 | 它给你 |
|---|---|---|
| **① 从主题生成** | 一句话主题（或一份文档） | AI 自主设计每页版式的**单文件 HTML 设计稿**，可放映 / 打印 PDF / 导出 pptx |
| **② 从 pptx 导入** | 一份**现成的 `.pptx`** | 保真底图 + **逐条高亮讲解**的播放器，可导出 MP4；也能把它导回**可编辑 pptx** |

> 「AI 自主设计」= 不是套模板。LLM 按内容决定版式：数据页画图表、概念页出卡片、封面做视觉冲击、时间线页做时间轴。

**两条路线可以一起用**：先用 ② 把旧 PPT 变成会动的讲解，或用 ① 从零做一份新稿。

---

## 二、快速开始

```bash
# 1. 依赖
python -m venv .venv
.venv\Scripts\activate          # Windows
pip install -r requirements.txt

# 2. 配置模型
copy .env.example .env          # 编辑 .env 填 ZHIPUAI_API_KEY
#    或者：启动后在界面「模型设置」里加自定义渠道（推荐，支持多供应商切换）

# 3. 启动
python app.py
# 浏览器打开 http://127.0.0.1:5000
```

**依赖外部程序（可选但影响功能）**

| 程序 | 用途 | 缺失后果 |
|---|---|---|
| **Microsoft PowerPoint** | 路线 ② 导出保真底图（COM） | 路线 ② 的 `faithful` 模式不可用，会提示安装 |
| **Chrome / Edge** | 截图与视频合成 | 截图、动画、MP4 不可用 |
| **ffmpeg** | 合成 MP4 | 视频按钮报错并给安装指引（`winget install ffmpeg`） |

## 三、路线 ① · 从主题生成设计稿

1. 顶部输入主题（例：`人工智能如何改变教育`），可调**密度**（精简 / 均衡 / 详尽）
2. 点生成 → 依次看到 `大纲 → 选风格 → 配图 → 设计 HTML`
3. 完成后进入**两栏工作区**：
   - **左栏**：对话修改、页面卡片（编辑文字 / 换图 / 排序 / 增删）
   - **右栏**：设计稿常驻预览，改一处右侧立刻更新（窄屏自动回退单栏）

**过程中可以打断**：打开「分步确认」后，会在 **大纲与风格**、**配图** 两个节点暂停，横幅上点「继续」放行，或「先改改」先调整 —— 不用等整条流水线跑完才发现方向不对。

**改一页不重跑全篇**：在右侧「AI 协作」面板**圈选某一页 / 某条要点**再说要求，只改被圈定的部分，其余页面连配图一起保留。

## 四、路线 ② · 把现成 pptx 变成会动的演示

### 4.1 在工作台里

侧栏 **「导入 PPTX 高亮讲解」** → 选一份 `.pptx` → 等十几秒 → 侧栏出现播放器入口。

完成后你会得到：

- **底图**：PowerPoint 自己渲染的每页 PNG（视觉 100% 保真，渐变/图表/圆角原样）
- **高亮锚点**：由 python-pptx 读出的**行级**文字坐标（不是整块文本框，所以高亮能贴着字走）
- **播放器**：逐条高亮、其余降暗，支持**步进讲解**（空格/→ 下一步，← 回退）

### 4.2 用命令行（更适合批量/自动化）

```bash
# ① pptx → 底图 + 几何 + 讲解单元
pptgen import 你的稿.pptx --out out/ --width 1920

# ② 生成高亮播放器
pptgen animate out/                    # 生成 out/player/index.html

# ③ 合成 MP4
pptgen video out/ --sec 4              # 整页翻页
pptgen video out/ --mode step --sec 2  # 按讲解单元逐步展开（教学用）

# ④ 反向：把产物导回可编辑 pptx
pptgen export out/deck.json -o 成品.pptx
```

**换一种思路**：如果不想保留原版式、想让它按内容重做，用 `--mode redesign`：

```bash
pptgen import 你的稿.pptx --out out/ --mode redesign
```

### 4.3 它读得懂 / 读不懂什么

| 内容 | 处理 |
|---|---|
| 文字、项目符号、图片、表格、基础图表 | ✅ 完整处理 |
| SmartArt、复杂组合图形、切换动效 | ⚠️ 降级（不参与高亮定位，但**底图里原样保留**） |
| 手工 PPT 里 `wrap="none"` 的文本框 | ⚠️ 若文本超框宽，会在输出里**明确警告**该页高亮精度降级为"整段" |

**诚实说明**：`python-pptx` 读不出 PowerPoint 的换行细节，所以高亮定位是**按字体度量推算**的，不是读 PowerPoint 内部排版。绝大多数标准汇报稿没有偏差，但页面上会给出警告，不会默默糊弄过去。

## 五、导出与产物

工作台侧栏「导出产物」可直接点开/下载：

| 格式 | 说明 |
|---|---|
| **HTML 设计稿** | 主产物，浏览器放映即可（方向键翻页）；「打印 → 存为 PDF」得到矢量 PDF |
| **pptx** | 两条来源：设计稿走**母版+占位符**（真可编辑，中文渲染为微软雅黑）；或 `builder` 的图片版 |
| **PDF** | 经 PowerPoint COM 导出（需装 Office） |
| **大纲 txt** | 纯文本大纲，便于二次编辑 |
| **动画播放器** | 逐元素揭示（产线 A）/ 高亮讲解（产线 B） |
| **MP4** | ffmpeg 合成，16:9 / 1280×720 / h264 |

## 六、风格、模板、品牌与配图

| 功能 | 怎么用 |
|---|---|
| **AI 自选风格** | 默认。从 6 套风格库（深空科技 / 极简商务 / 清新浅色 / 暖调人文 / 活力渐变 / 自然墨绿）按主题判断 |
| **内置模板** | 侧栏选一套色板 + 版式骨架（选中后跨生成保留，可清除） |
| **参考稿识别** | 上传一张设计图或 HTML，AI 识别其配色与气质并仿制 |
| **品牌模板** | 填品牌名 + 主色（`#RRGGBB`），覆盖强调色并注入设计指引；传空即清除 |
| **一键换色** | 对已有设计稿直接改 `:root` 变量（毫秒级，不重生成） |
| **配图开关** | `runtime_config.json` 的 `images` 键（缺省开）。**上游生图慢或质量差时建议关掉**——关掉后走纯排版路线，配图+设计阶段可从约 6 分钟降到 50 秒 |

## 七、命令行（CLI）参考

`pptgen` 的 5 个子命令。**stdout 恒为一行 JSON**（便于脚本/agent 解析），进度信息走 stderr。

### `pptgen import <pptx>`

| 参数 | 说明 |
|---|---|
| `--out` | 输出目录，默认 `output/pptx_src/<稿名>/` |
| `--mode {faithful,redesign}` | 忠实还原（默认）/ 交 AI 重新设计 |
| `--width {1280,1920,2560}` | 底图导出宽度 |
| `--pages N` | 只处理前 N 页 |
| `--no-com` | 不用 PowerPoint 导底图（无 Office 环境） |

### `pptgen animate <dir>`

| 参数 | 说明 |
|---|---|
| `--dim` | 非当前条目降暗比例（`0 < dim < 0.6`） |
| `--auto-ms` | 自动讲解步进间隔 |
| `--highlight` | 模式开关（默认即高亮） |

### `pptgen video <dir>`

| 参数 | 说明 |
|---|---|
| `--sec` | 每页时长（秒） |
| `--fps` | 帧率（默认 25） |
| `--fade` | 转场时长，需 `0 < fade < sec` |
| `--mode {page,step}` | 整页翻页 / 按讲解单元逐步展开 |
| `-o, --out` | 输出 mp4 路径 |

### `pptgen export <deck.json>`

| 参数 | 说明 |
|---|---|
| `-o, --out` | 输出 pptx 路径 |
| `--template` | 自定义母版 `.pptx`（沿用它的母版/字体/主题色） |
| `--no-com` | 不支持的对象走占位 |

### `pptgen deck "<主题>"`

走产线 A 的全自动流水线（等价于工作台点一次生成）。

## 八、给 agent 用（skill）

skill 已随项目提供：`skill/ppt-anim/`（安装后位于 `~/.agents/skills/ppt-anim/`）。
它是一层**薄封装**——逻辑全在 `cli.py`，skill 只负责"告诉 agent 什么时候用、怎么调"。

```bash
# agent 侧等价调用（脚本会自动找到项目与 venv）
python ~/.agents/skills/ppt-anim/scripts/pptgen.py animate out/
```

定位顺序：`$PPTGEN_HOME` → 向上查找含 `cli.py` 的目录 → 默认安装路径。都找不到时给明确提示。

**适用场景**：用户给一份 `.pptx` 要求做讲解视频 / 逐条高亮演示 / 把产物导回可编辑 pptx。
**不适用**：从主题创作新 PPT（那用 `ppt-maker` skill）。

## 九、故障排查

| 现象 | 原因与处置 |
|---|---|
| 提示「未检测到 PowerPoint」 | 路线 ② 的保真底图依赖 Office COM。装 Office，或改用 `--no-com`（放弃保真底图） |
| 导出 pptx / PDF 报 500 | 多为上游生图返回了 **WebP**（python-pptx 不接受）。项目已自动转 PNG；若仍出现，查看 `output` 下配图是否为有效 PNG |
| 生成很慢 / 卡在配图 | 上游生图服务慢。**关掉配图开关**（`runtime_config.json` 的 `images: false`）走纯排版 |
| 报 `403 Insufficient Balance` / 预扣费失败 | 模型账户余额不足。换渠道或充值（界面「模型设置」可加渠道） |
| 播放器页面全黑 | 底图缺失或路径不对。检查 `out/bg/` 是否有一组 `slide_N.png`；播放器已会对缺图报错而不是静默黑屏 |
| 导出的视频里图表是空白 | 旧版本问题（截图时动画未稳定）。现已三重确定化；如果复现请提 issue 并附设计稿 HTML |
| 高亮块位置偏 | 该页可能用了 `wrap="none"` 且文本超框宽 —— 输出里会有明确警告，表示该页精度降级为段级 |
| 首次导入 pptx 要等 ~25 秒 | 正常：每次导入都会新建并关闭一个 PowerPoint 实例（约 5.8s 启动 + 关闭延迟）。这是为**不干扰你正在编辑的 PowerPoint** 付出的代价 |
| 端口 5000 被占用 | 关闭占用进程，或改 `app.py` 末尾的端口 |
| 视频合成报错 | 检查 ffmpeg 是否安装（`winget install ffmpeg`），以及 `--fade` 是否小于 `--sec` |

## 十、性能参考（实测）

| 项目 | 数值 |
|---|---|
| 单页底图导出（CLI） | **0.82 秒/页**（10 页 8.22 秒 @1920 宽） |
| 一次完整导入（含启动/关闭 PowerPoint） | 约 **2.5 秒/页**（10 页约 25 秒） |
| 高亮单元定位 | 10 页 → 27 个讲解单元，毫秒级 |
| 视频合成 | 10 页 × 2 秒 → 12.8 秒成片（含转场）约数十秒 |
| 关闭配图后（产线 A） | 配图+设计阶段 366 秒 → **51 秒** |

## 十一、注意事项

- **本地单用户工具**：设计上不面向公网，没有鉴权与多用户隔离。请不要直接暴露到外网。
- **模型 Key 不入库**：配置在 `runtime_config.json`（已 gitignore）或 `.env`。
- **AI 产物需人工过一眼**：LLM 生成的版式偶有标题出界/溢出（HTML 侧目前没有几何门禁，已知风险），导出前建议在设计稿预览里扫一遍。
- **它不会动你正在编辑的 PowerPoint**：这条有专门的守卫（只关闭自己打开的稿件），也有回归测试保着。
